# 1Panel mutation request shapes

```
panel version : v2.3.2
spec source   : core/cmd/server/docs/swagger.json @ tag v2.3.2
swagger       : 2.0   basePath /api/v2
shapes digest : sha256:82fc2f6f1cd331802eeaf026f75de3f58d7ea49cd5fb4823442535e2718cdb1d
```

Generated by `generate.mjs` from the spec that ships inside the panel. Field names,
required flags and enums are read out of that file — never written from memory.
Do not hand-edit.

## Scope

Valid only for the panel version above: it is the request shapes of that specific
version. SKILL.md owns the gate that decides when this file may be used; never write
from it for a panel reporting a different version, and never from memory.

```bash
curl -sSL -o /tmp/sw.json \
  https://raw.githubusercontent.com/1Panel-dev/1Panel/<version>/core/cmd/server/docs/swagger.json
node generate.mjs /tmp/sw.json --version=<version>
```

`*` required · `enum=[...]` only accepted values · **cascade** destroys something else
as a side effect and must be decided by the user, never defaulted.
